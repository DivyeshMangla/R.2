# Engine recording

`engine-load.wav` uses **Car Engine Loop 96kHz, 4s** by **qubodup**.

- Source: https://opengameart.org/content/car-engine-loop-96khz-4s
- Original download: https://opengameart.org/sites/default/files/engine-loop.7z
- License selected from the author's offered licenses: **Creative Commons Attribution 3.0 Unported** — https://creativecommons.org/licenses/by/3.0/
- Original file: `engine-loop/engine-loop-1-normalized.wav` (44.1 kHz, 16-bit stereo, 4 seconds).
- Changes for this game: stereo mixed to mono, DC removed, a 50 ms equal-power overlap added at the loop join, peak normalized to 0.78. Result: 44.1 kHz, 16-bit mono, 3.95 seconds, 348,434 bytes.
- Use: a restrained mechanical texture during loaded mid/high RPM, mixed with original procedural idle, intake, tire, road and wind layers. Pitch and level change with the audio powertrain model.

The recording is credited in the in-game field guide. These modifications do not imply endorsement by the original author.
